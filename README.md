# 🎈 Helium Rising V2.0

A balloon that never stops climbing. Steer around birds, drones, jets, storms and
rockets, bank every metre you earn, and spend it in the shop.

**Play:** https://PHONG-HACKER.github.io/Helium-Rising-Claude/

## Controls

### Keyboard

| Key | Action |
|---|---|
| `←` `→` | steer |
| `↑` | boost · `↓` vent helium |
| `/` | bubble shield (5s) |
| `.` | slow motion (10s) |
| `,` | future vision (25s) |
| `;` | magnet (15s) |
| `[` `]` | boost speed · `M` mute · `P` pause |
| `R` | end the run and go back to the start screen |

### Mobile

Flip the toggle in the top-left corner of the start screen. You get an on-screen
joystick in the bottom-left — sideways to steer, up to boost, down to vent — and
power-up buttons down the right-hand side.

## What's in it

- 17 obstacle types across 8 altitude zones, with per-run weather and generative music
- Collect bubble shards and clock pieces for shields and slow-motion; everything you
  collect is saved for your next flight
- **Boss fight at 3,000 m** — an alien mothership with 5 lives rains meteoroids on you.
  Turrets drop in near your balloon; grab one and it fires back. Beat it for the
  ALIEN SLAYER title
- A shop with power-ups, 16 balloon skins, a 23-trail gacha and 20 unlockable titles
- **ADMIN ABUSE** every Saturday: ×2 meters, ×4 gacha luck and half price on everything,
  with a live countdown on the start screen
- Separate player profiles, each with their own meters, inventory and record history
- **Save and load codes** — the buttons in the bottom-left corner turn your whole
  account into one short code you can copy, keep, and paste back in on any computer

Everything lives in a single `index.html` — no build step, no dependencies.
