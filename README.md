# 🎈 Helium Rising

A balloon that never stops climbing. Steer around birds, drones, jets, storms and
rockets, bank every metre you earn, and spend it in the shop.

**Play:** https://PHONG-HACKER.github.io/Helium-Rising-Claude/

## Controls

| Key | Action |
|---|---|
| `←` `→` | steer |
| `↑` | boost · `↓` vent helium |
| `/` | bubble shield (5s) |
| `.` | slow motion (10s) |
| `,` | future vision (25s) |
| `;` | magnet (15s) |
| `[` `]` | boost speed · `M` mute · `P` pause |

## What's in it

- 17 obstacle types across 8 altitude zones, with per-run weather and generative music
- Collect bubble shards and clock pieces for shields and slow-motion; everything you
  collect is saved for your next flight
- A shop with power-ups, 13 balloon skins, a trail gacha and unlockable titles
- Separate player profiles, each with their own meters, inventory and record history

Everything lives in a single `index.html` — no build step, no dependencies.
